## 4. PATTERNS & CONVENTIONS

**Component Pattern:** Named exports from functional React components.

```jsx
// PascalCase for components, camelCase for non-components
export const Navbar = () => { ... };
export default function Footer() { ... };
```

**Styling:** Tailwind CSS utility classes inline. Dark mode via CSS variables defined in `globals.css` under `@theme`.

**Animations:**
- GSAP + ScrollTrigger: `Firstprinciple.jsx` uses `gsap.registerPlugin(ScrollTrigger)` for scroll-based reveals
- Framer Motion: `HeroSection.jsx` (parallax), `JoinSection.jsx` (rotating SVG)

**Fonts:** Next.js local font loading via `app/fonts.js` for Brittany (signature). Google Fonts (Inter, Kepler) via `app/layout.js`.

**Data:** Static JS files in `/data` export arrays/objects consumed by components.

**Path Aliases:** `@/*` resolves to project root (configured in `jsconfig.json`).

## 6. MODIFICATION RULES

### Mandatory Pre-Read
Before ANY code changes, read `AGENTS.md` — it documents Next.js 16 breaking changes and deprecations. This project explicitly requires checking `node_modules` documentation.

### Animation Layer Caution
Do not mix GSAP and Framer Motion state/props unexpectedly. `Firstprinciple.jsx` uses GSAP; `HeroSection.jsx` and `JoinSection.jsx` use Framer Motion. Adding animations to GSAP components should use GSAP; adding to Framer components should use Framer.

### Layout Stability
`app/layout.js` wraps ALL pages with Navbar, Footer, and popup state containers. Modifying this file affects every route.

### Popup State Architecture
`FaqPopup` and `ProfessorPopup` are mounted in `app/layout.js` as persistent components, likely controlled via React context or global state from Navbar. Do not move these to individual pages without preserving trigger linkage.

### Font Configuration
`app/fonts.js` exports Brittany as a CSS variable. `globals.css` references this font. Changes to font files require updating both.

### Dark Mode
CSS variables in `globals.css` under `@theme` control theming. All new components should reference these variables, not hardcoded colors.

### Path Aliases
Use `@/` prefix for imports when possible. Do not remove or modify `jsconfig.json` path aliases without updating all existing `@/*` imports (31 files).

### Static Data Integrity
`data/professors.js` and `data/faqdetails.js` are the single sources of truth for their respective features. Do not hardcode equivalent data in components.

### Next.js 16 Compatibility
This project uses Next.js 16 with React 19. Verify any new dependencies support this combination. Avoid patterns flagged as deprecated in Next.js 16 changelog.
